# Приложения БИЛДИНФОТЕХ для планшетов Aquarius NS220

Три отдельных приложения на рабочем столе планшета:

| Приложение | Что внутри | Откуда |
|---|---|---|
| **Калькулятор** | Штатный калькулятор Android (AOSP, `com.android.calculator2`) | Уже в прошивке 8.1 — при облегчении системы **не удалять** |
| **Расчёты** | Поверочные расчёты КЖ, КМ, ОиФ, АР, утилиты (резерв webcad.pro), экспорт в Word | `webcad.html` + `webcad/` |
| **Анализ свай** | Анализатор записей «Спектр» + экран «Прибор / Bluetooth» | `pile-analyzer.html` + нативный модуль |

Калькулятор стоимости (СБЦП) в приложения не входит.

Веб-калькуляторы — единственный источник: правки на сайте c.bit-exp.ru автоматически попадают
в следующую сборку APK. Приложения работают полностью без интернета (разрешения INTERNET нет).

## Сборка

Автоматически в GitHub Actions (`.github/workflows/android.yml`) при каждом изменении
`android/`, `pile-analyzer.html`, `webcad*`. Готовые APK — во вкладке **Releases** репозитория.

Один раз задайте секреты подписи (Settings → Secrets and variables → Actions):
`ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
Без них APK подписываются случайным отладочным ключом и не обновляются поверх установленных.

Локально (нужны JDK 17, Android SDK, Gradle 8.14):

```
python3 android/tools/sync_web.py
gradle -p android assembleRelease
```

## Что делает оболочка (модуль `shell`)

- открывает страницы из assets по `https://appassets.androidplatform.net/…` — работает localStorage;
- «Скачать»/экспорт (CSV, Word) → `Загрузки/БИЛДИНФОТЕХ/<приложение>/` с кнопкой «Открыть»;
- `window.print()` → системная печать Android, в т.ч. «Сохранить как PDF» (отчёт по сваям);
- «Открыть папку…» → системный выбор папки, структура `Объект/Свая/удар.wav` сохраняется;
- предупреждает, если Android System WebView старше 90 — его нужно обновить в прошивке.

## Анализ свай: прибор и Bluetooth

Кнопка **«Прибор / Bluetooth…»** рядом с «Открыть файлы…»:

1. **Данные «Спектр» на этом планшете** — если приложение прибора стоит на том же планшете,
   его папка `Spectr/data/Объект/Свая` читается напрямую, объект открывается одним нажатием.
2. **Принято по Bluetooth** — файлы `.wav` или архивы `.zip`, переданные штатной передачей
   файлов Android (с прибора, телефона, ноутбука). Пока приложение открыто, новые файлы
   ловятся автоматически: появляется окно «Принято по Bluetooth — Загрузить в анализ».
3. **Прямое подключение (SPP)** — к сопряжённому прибору через последовательный порт Bluetooth.
   Весь поток пишется в `Загрузки/БИЛДИНФОТЕХ/Анализ свай/Bluetooth <дата>/поток_….bin`,
   WAV-записи (с блоком `<META>`) вырезаются из потока автоматически (`WavStreamParser`).
   Протокол обмена «Спектр» не опубликован: если прибор шлёт данные в своём формате,
   по снятому дампу дописывается разбор — точка расширения `WavStreamParser`.
