Разметка документов и OCR

Конвертер в духе Microsoft MarkItDown: PDF, Word, Excel, PowerPoint, HTML, CSV и изображения превращаются в чистый Markdown. Сканы и фото распознаются встроенным OCR (русский + английский). Файлы не покидают ваш браузер.

Только браузер · версия 3.0

Без установки программ, Python и локального сервера. При первом запуске браузер загружает библиотеки и модели из интернета. Документы обрабатываются на вашем устройстве. Для формул нужна видеокарта с WebGPU; обычный OCR работает на процессоре в Worker.

Числа автоматически помечаются [?…]. Таблицы и LaTeX — черновик, сверяйте по сохранённым страницам. Фото с перспективой и тенями не поддерживаются: нужен скан.

Результат сохраняется по страницам в браузере. Для продолжения после закрытия выберите исходный файл повторно с тем же режимом. При выборе папки внутри неё создаётся «Распознанные документы».

За один раз обрабатывается одна страница; максимум 4 млн пикселей, один OCR Worker. Видеопамять управляется браузером: режим формул может быть тяжёлым. Закрытая вкладка не продолжает распознавание.

Перетащите файлы сюда или нажмите для выбора PDF · DOCX · PPTX · XLSX/XLS · CSV · HTML · TXT/JSON/XML · JPG/PNG/WEBP/BMP
Режим формул работает на видеокарте вашего устройства (WebGPU): при первом запуске скачивается модель ~650 МБ, далее она берётся из кэша браузера. Скорость зависит от устройства; при нехватке видеопамяти выберите обычный OCR. Формулы выходят в LaTeX ($…$), но нейросеть иногда искажает слова — сверяйте с оригиналом.
Как это работает
  • Текст из PDF извлекается с сохранением абзацев и заголовков; страницы без текстового слоя (сканы) автоматически отправляются на OCR.
  • Word → заголовки, списки, таблицы и ссылки; формулы Word (OMML) переводятся в LaTeX для ручной сверки; рисунки в документе распознаются OCR и вставляются цитатой.
  • Формулы в PDF и на сканах (СП, ГОСТ) обычный OCR не читает. Режим «С формулами» распознаёт страницу нейросетью и выдаёт текст с формулами в LaTeX.
  • Excel и CSV → таблицы Markdown по листам; PowerPoint → заголовки слайдов, текст, таблицы и заметки докладчика.
  • В оригинальном MarkItDown OCR работает только через облачную LLM или Azure; здесь он локальный (Tesseract), ничего не отправляется на серверы. Модули и языковые данные OCR один раз скачиваются из интернета.
Результат конвертации носит справочный характер; сканы проверяйте глазами. Главная: bit-exp.ru/c/.
