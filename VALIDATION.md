# Тестовая сборка OCR

Ветка предназначена для локального тестирования и не заменяет основную ветку сайта.

- Сравнение чисел выполняется по таблице, строке и столбцу с сохранением знаков.
- Все автоматически прочитанные числа помечаются до визуальной сверки.
- Установка в новом venv проверена; текстовый и SERVER-распознаватель ячеек проверены
  с заблокированными Python socket-соединениями.
- Регрессионные проверки чисел, таблиц и HTTP выполняются в GitHub Actions.
- Полный повторный прогон пяти ГОСТов в двух режимах выполняется локально;
  агрегированная таблица будет добавлена следующим коммитом. Документы не публикуются.

Ограничения: браузерная модель формул пока требует первоначальной сетевой загрузки;
встроенный браузер проверен, отдельный Chrome с запросом доступа к локальной сети — нет.
Отдельной Cyrillic SERVER модели в используемой версии RapidOCR нет: SERVER применяется
к числовым ячейкам, русский текст читается MOBILE.
