# Проверка тестовой сборки OCR — 13 ноября 2026

Это тестовая ветка, не готовая замена рабочей программы. Основной сайт не обновлён.

## Числа до / после

Сравнение выполнено одним текущим оценщиком для старых и новых результатов: таблица, строка, столбец, знак числа. Найденные числа включают текст вне таблиц. Это не прежняя метрика «мешок чисел». Полный OCR пяти документов выполнен в auto и ocr; после исправлений таблиц и подписей повторены соответствующие стадии из сохранённых результатов. Отдельного полного прогона после каждого подпункта задания нет.

Это не доказательство точности OCR и не означает, что проверять нужно лишь небольшую долю документа. Есть серьёзные ухудшения позиционного совпадения, особенно ГОСТ 8509-93 в ocr; требуется разбор сборки таблиц и распознавания. Для расчётов результат без визуальной сверки использовать нельзя.

## Ресурсы и запуск

Панель работает в браузере, OCR — в локальном Python. Первоначально install.bat устанавливает библиотеки и модели (около 150 МБ только модели). Драйверы не устанавливаются. PDF, изображения и Markdown сохраняются на диске. Обычный OCR и SERVER числовых ячеек проверены с заблокированными socket-соединениями.

Один документ обрабатывается за раз. На инференс выделено не более половины логических ядер, максимум 4 потока; OpenCV ограничен так же, приоритет Windows понижен. Перед подготовкой/распознаванием проверяется свободная ОЗУ: резерв 20%, минимум 1,5 ГБ. Проверяется размер листа до PDF-рендера, предел 45 Мп. Это предупредительные проверки, а не жёсткая квота CPU/памяти.

Небольшой реальный запуск OCR на синтетическом листе 900×1200: 20 логических CPU, бюджет 4 потока, 1,829 с, средняя загрузка всей машины 17,04%, пик рабочего набора процесса 255,7 МиБ. Не измеряет худший случай для больших PDF. Тесты нехватки ОЗУ и большого листа проверяют отказ до тяжёлой работы.

15 модульных тестов и 33 локальные проверки прошли. Подготовка тестового PDF с ограничениями ресурсов прошла. Отдельная Windows-сборка GitHub Actions прошла установку, модульные тесты и HTTP-проверки.

## Что ещё не подтверждено или не закончено

- Точность таблиц недостаточна; есть регрессии в таблице выше. Общая готовность задания не заявляется.
- Не выполнены отдельные пять документов × два режима после каждого индивидуального подпункта; есть полные сравнительные прогоны и повтор изменённых стадий.
- Полный прогон пяти документов в precise не проведён. SERVER применяется к числовым ячейкам: готового Cyrillic SERVER в установленной версии нет, русский текст читает MOBILE.
- Нейросетевой LaTeX в браузере требует отдельной первоначальной загрузки около 650 МБ. Полностью автономный комплект формульной модели не подготовлен; вырезки и ручная правка остаются.
- Chrome с разрешением доступа к локальной сети отдельно не проверен; основной интерфейс — localhost. Встроенная панель проверена.
- Проверены новый venv и установка на Windows GitHub Actions, но не ручной запуск start.bat на отдельном чистом пользовательском компьютере.
- Очередь batch, продолжение и отчёты реализованы; полный аварийный ночной сценарий с перезагрузкой компьютера не проверен.
- Соотношения проверяются локальным безопасным вычислителем с той же записью правил; автоматический вызов именно CLI relcheck.py не используется.
- Установленные ограничения не являются жёстким пределом памяти процесса и не гарантируют отсутствие задержек при любой нагрузке других программ.

Исходные документы, распознанные тексты, ключ доступа, журналы, модели и venv в репозиторий не отправляются.
