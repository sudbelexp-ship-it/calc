# Браузерная версия 3.0 — 14 ноября 2026

Публикуемый интерфейс работает без Python, BAT и HTTP-сервера на компьютере пользователя.
Сайт отдаёт статические файлы; документы обрабатываются внутри браузера.
Библиотеки и веса моделей загружаются из CDN/Hugging Face. Полностью автономный
холодный запуск без интернета не поддерживается.

## Ограничения

- Браузерный конвейер не является переносом всех алгоритмов Python.
  Пять ГОСТов в режимах auto/ocr в браузере ещё не оценены по позициям ячеек.
  Нельзя переносить на него результаты прежнего Python-бенчмарка.
- Tesseract не восстанавливает сложные числовые таблицы и формулы достоверно.
  GLM-OCR — дополнительный режим WebGPU; LaTeX не считается сверенным.
  Числа в обычном тексте помечены [?…]; математика сохраняется как LaTeX
  с предупреждением на странице, а не вставкой меток внутрь формулы.
- Пока сохраняются страницы целиком, автоматических отдельных вырезок
  каждой таблицы/формулы и проверки соотношений в браузере нет.
- Папки выбираются через File System Access API (Chrome/Edge).
  Их системные диалоги в рамках этого теста не проходились;
  запись/восстановление проверялись файловыми тестами API-адаптера.
- После закрытия вкладки очередь останавливается. Для продолжения нужно
  повторно выбрать исходные файлы и тот же режим/язык/диапазон страниц.
- Один документ, одна страница и один OCR Worker одновременно;
  изображение ограничено 4 млн пикселей (GLM: 2,2 млн), файл — 250 МБ.
  Это не жёсткая квота всей RAM/VRAM: браузер сам управляет памятью модели.
  GLM работает в отдельном Worker, выгружается при переходе на Tesseract.
- Пауза действует между страницами. Удаление активной карточки отменяет
  запущенное распознавание Worker; уже записанные результаты сохраняются.
- Browser cache может быть очищен браузером. Выбирайте папку результата
  или сохраняйте ZIP. Встроенные TIFF-пакеты/многостраничные изображения
  не заявлены как поддерживаемый способ импорта — используйте PDF.

## Разработка

`python build-browser.py` пересобирает HTML из browser-source-before.html,
browser-storage.js и browser-pdf.js, а также отдельный browser-glm-worker.js.
Python нужен разработчику для сборки, пользователю он не нужен.

Проверки: `node browser-tests.cjs`, `node browser-recovery-tests.cjs`.
Для хостинга нужны markitdown.html, browser-glm-worker.js и существующий theme.js.
razmetka.html может содержать копию markitdown.html для старых ссылок.
